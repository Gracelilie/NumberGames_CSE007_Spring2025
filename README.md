##  Description
This project contains two Java programs:
1. **GuessingGame.java** – A simple game that challenges the user to guess a randomly generated number within a given range. It gives feedback on whether the guess is too high or too low and counts the number of attempts.
2. **NumConversion.java** – A number conversion utility that converts numbers between different bases (e.g., binary, decimal, hexadecimal) while validating user input.

Each program reinforces conditional logic, loops, and input validation in Java.
